# Release 0.19.7 – Schlankeres öffentliches Repository, kürzere technische Übersicht

Stand: 2026-11-03. Release ohne Änderung an der Anwendung: Das öffentliche Quellarchiv
enthält nur noch, was für den Betrieb nötig ist, dazu die Nutzer-Dokumentation.

## Für den Betreiber

- Kein Schema-Schritt (bleibt 25).
- Keine API-Änderung, keine Änderung an Oberfläche oder Verhalten.
- Keine Betreiber-Aktion nötig. Wer von einer Version vor 0.19.3 kommt und WAMS im LAN
  öffnet, braucht eine `.env` mit `WAMS_BIND_ADDRESS=0.0.0.0` (`INSTALL.md`, Abschnitte 5
  und 9).
- Die Assets werden mit `?v=0.19.7` ausgeliefert.

## Öffentliches Repository

- Das Archiv `wams-public-<version>.tar.gz` enthält `backend/`, `frontend/`, `Dockerfile`,
  `compose.yaml`, `.env.example`, `.dockerignore`, `.gitignore`, `LICENSE`, die
  Nutzer-Dokumentation (`README.md`, `INSTALL.md`, `NODE_SETUP.md`, `SECURITY.md`,
  `SIGNET.md`, `TECHNICAL_OVERVIEW.md`) und die Release-Notizen unter `docs/releases/`.
- Tests, Entwicklerwerkzeuge sowie Entwickler- und Spezifikationsdokumente sind nicht mehr
  Teil des öffentlichen Archivs. Die Entwicklung findet in einem privaten Repository statt;
  Fehlermeldungen und Vorschläge sind über GitHub Issues willkommen.
- Verweise in der Nutzer-Dokumentation und in den Release-Notizen auf nicht veröffentlichte
  Dateien sind entfernt oder umformuliert.

## Dokumentation

- `TECHNICAL_OVERVIEW.md` ist auf eine Seite „How WAMS works“ gekürzt: Architektur
  (Container, Node-RPC, SQLite, Browser-Oberfläche), Grundbegriffe (Acquisition, Exit,
  Provenance, No acquisition (verified), Needs Review), Datenfluss und Grenzen.
- `README.md`: Dokumentationsübersicht angepasst, ein Satz zur Entwicklung.
