# Release 0.19.8 – Vereinfachte Installationsanleitung, Umbrel-Hinweise

Stand: 2026-11-03. Release ohne Änderung an der Anwendung: Die Installationsanleitung ist
neu gegliedert und beginnt mit einem kurzen Quick install zum Kopieren und Einfügen.

## Für den Betreiber

- Kein Schema-Schritt (bleibt 25).
- Keine API-Änderung, keine Änderung an Oberfläche oder Verhalten.
- Keine Betreiber-Aktion nötig. Das Update geht wie im neuen Abschnitt „Update“ von
  `INSTALL.md` beschrieben.
- Die Assets werden mit `?v=0.19.8` ausgeliefert.

## Dokumentation

- `INSTALL.md` beginnt mit **Quick install** für eine frische Ubuntu-VM: ein Block zum
  Kopieren und Einfügen (Docker, Download mit Prüfsumme, `.env` mit
  `WAMS_BIND_ADDRESS=0.0.0.0` für den Zugriff aus dem Heimnetz samt Warnhinweis, Start,
  Health-Check mit erwartetem Verhalten), danach Browser, Node Settings und die
  Getting-started-Checkliste. Variablen statt Platzhaltern in spitzen Klammern, damit die
  Befehle beim Einfügen in die Shell funktionieren.
- Kurzer Abschnitt **Update**; alles Weitere unter **Advanced**: Docker per apt, optional
  Benutzer, SSH-Schlüssel (auch für Windows) und Firewall, Git als Alternative zum
  Release-Archiv, Variablen der `.env`, Prüfungen nach dem Start, Backup und Restore,
  Fehlersuche.
- `.env` ist für den Zugriff von einem anderen Rechner nötig, für die Node-Verbindung
  nicht (Node Settings). `WAMS_BIND_ADDRESS` ist eine Adresse des WAMS-Servers, nicht die
  des zugreifenden PCs; den Zugriff auf einen PC beschränkt eine Firewall-Regel
  (`SECURITY.md`).
- `NODE_SETUP.md`, Abschnitt Umbrel: wo die RPC-Zugangsdaten zu finden sind (App-Oberfläche
  oder per SSH auf dem Umbrel) und wie die Erreichbarkeit vom WAMS-Server geprüft wird.
- `README.md`: Quick start verweist auf den Quick install.
