# Release 0.18.12 – UNIQUE-Index auf Exit-TXID, Blockhöhe für nachträglich bestätigte Tx (P2-REST)

Stand: 2026-10-29. Patch-Release mit P2-REST (Branch `fix/p2-rest`: P2-N3-Rest, P2-N8-Rest,
R2-06). Owner-Entscheidungen P2-N3/P2-N8 (intern dokumentiert, 2026-10-29).

## Für den Betreiber

- **Schema 24 → 25: vor dem Update die Datenbank sichern** (`INSTALL.md`, Abschnitt 10).
  Die Migration läuft beim Start automatisch und nur vorwärts.
- Neu ist der UNIQUE-Index `ux_exchange_exits_txid` auf `exchange_exits.txid`. Er wird bei
  jedem Start angelegt, sofern er fehlt.
- Gibt es schon mehrere Exits auf dieselbe TXID, startet die App trotzdem, aber ohne Index.
  Das Log nennt dann je TXID die betroffenen Exit-IDs („unique index ux_exchange_exits_txid
  not created“). Nach dem Löschen der Doppelten legt der nächste Start den Index an.
- Die Assets werden mit `?v=0.18.12` ausgeliefert.

## Behoben

- Transaktionen, die beim ersten Laden unbestätigt im Cache landeten, bekommen nach der
  Bestätigung Blockhöhe und Blockzeit (erneute Prüfung beim Laden).
