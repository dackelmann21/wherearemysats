# Release 0.19.4 – Hängende Coverage-Anfrage behoben, Testzeitlimit (FLAKY-1)

Stand: 2026-11-02. Patch-Release mit FLAKY-1 (Branch `fix/flaky-1`).

## Für den Betreiber

- Kein Schema-Schritt (bleibt 25).
- Keine API-Änderung.
- Keine Betreiber-Aktion nötig; die `.env` bleibt unverändert.
- Die Assets werden mit `?v=0.19.4` ausgeliefert.

## Behoben

- Eine Coverage- bzw. Inventory-Anfrage konnte in seltenen Fällen hängen bleiben, bis der
  Browser die Verbindung trennte. Ursache: Der Abbruch des Disconnect-Watchers wurde
  verschluckt, sodass die Anfrage auf ihn wartete. Der Watcher endet jetzt zusätzlich über
  ein Flag.

## Entwicklung

- Zeitlimit je Test von 120 s in der Testsuite (nicht Teil des öffentlichen Archivs).
