# Release 0.19.9 – Manueller Download-Weg, kleine Bereinigungen

Stand: 2026-11-03. Release ohne Änderung an der Anwendung: Die Installationsanleitung
beschreibt zusätzlich den Download im Browser, dazu kleine Korrekturen.

## Für den Betreiber

- Kein Schema-Schritt (bleibt 25).
- Keine API-Änderung, keine Änderung an Oberfläche oder Verhalten.
- Keine Betreiber-Aktion nötig. Das Update geht wie im Abschnitt „Update“ von
  `INSTALL.md` beschrieben.
- Die Assets werden mit `?v=0.19.9` ausgeliefert.

## Dokumentation

- `INSTALL.md`, neuer Abschnitt **Manual download (alternative to step 2)** direkt nach
  dem Quick install: beide Dateien (`wams-public-<version>.tar.gz` und `.sha256`) im
  Browser von der Releases-Seite laden, Prüfsumme optional schon auf dem eigenen Rechner
  prüfen (Windows PowerShell `Get-FileHash`, Linux `sha256sum -c`, macOS
  `shasum -a 256 -c`), mit `scp` (unter Windows ab Windows 10 enthalten) oder einem
  grafischen Werkzeug wie WinSCP auf den Server kopieren, dort ohne `curl` prüfen und
  entpacken, danach weiter mit Schritt 3 des Quick install. Der Abschnitt „Update“ nennt
  den manuellen Weg als Ersatz für die beiden `curl`-Zeilen.
- `INSTALL.md`: getestet auf Ubuntu Server 22.04 LTS; 24.04 sollte genauso funktionieren.
- Kommentare im Quellcode verweisen nicht mehr auf nicht veröffentlichte Dokumente.
- Release-Notizen 0.19.7 verweisen auf die Abschnitte „Quick install“ und „Update“ von
  `INSTALL.md`.

## Build

- `.dockerignore` schließt `wams-public-*.tar.gz*` aus: Das heruntergeladene Archiv und
  seine Prüfsummendatei im Installationsverzeichnis gehen nicht mehr in den
  Docker-Build-Kontext ein.
